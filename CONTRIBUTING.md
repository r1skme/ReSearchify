# Contributing to ReSearchify

[Русский](#по-русски)

Bug reports, reproducible benchmarks, documentation fixes, and pull requests
are welcome.

1. Open an issue for larger changes; explain the problem and expected behavior.
2. Make your change on a branch or a GitHub fork of this repository.
3. Run the relevant CMake/CTest checks and include a short explanation of results.
4. Open a pull request against this repository. Keep commits and comments clear.

**Source policy:** ReSearchify is free to use but is not open source. You may
study and improve it, and propose upstream patches. You may not reuse its
source code in another project or distribute modified builds without written
permission. See [LICENSE](LICENSE).

**Contribution rights:** You retain copyright in the code you wrote. By
intentionally submitting it to ReSearchify, you grant r1skme permission to
use, modify, distribute, sublicense, and relicense it in ReSearchify and
related distributions, including proprietary builds, as set out in LICENSE.
Only submit code you have the rights to contribute.

## По-русски

Можно присылать баг-репорты, честные бенчмарки, исправления документации
и Pull Request.

1. Для крупных изменений сначала открой Issue.
2. Работай в отдельной ветке или форке GitHub.
3. Запусти тесты и приложи результат.
4. Открой PR в исходный репозиторий.

**Код нельзя переносить в другие проекты или распространять изменённые
сборки без письменного разрешения.** Самой программой можно бесплатно
пользоваться в личных и коммерческих задачах. См. [LICENSE](LICENSE).

Права на написанные тобой изменения остаются у тебя, но отправляя PR,
ты даёшь автору проекта права на их использование, изменение и выпуск
в составе ReSearchify, включая закрытые сборки, на условиях LICENSE.
