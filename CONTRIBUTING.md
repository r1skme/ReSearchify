# Contributing to ReSearchify

[Русский](#по-русски)

Bug reports, benchmarks, documentation and pull requests are welcome.

1. Open an issue first for larger changes.
2. Make your change in a separate branch or GitHub fork.
3. Run the relevant CMake/CTest checks. Include results and reproducible benchmarks when performance changes.
4. Open a pull request with a short explanation of what changed and why.

ReSearchify is licensed under **GNU GPLv3 only** (`GPL-3.0-only`). Contributions to this repository are submitted under the same license, with no additional contributor license agreement. Keep copyright notices. Submit only code you have the rights to contribute and check third-party license compatibility.

## По-русски

Можно присылать ошибки, бенчмарки, исправления документации и Pull Request.

1. Для крупных изменений сначала открой Issue.
2. Работай в своей ветке или форке.
3. Запусти тесты и приложи результаты. Для оптимизаций укажи условия измерений.
4. Открой PR с коротким описанием изменений.

**Все изменения в этом репозитории принимаются на условиях GPLv3** (`GPL-3.0-only`). Дополнительное соглашение о передаче прав не требуется. Сохраняй уведомления об авторских правах и не добавляй код с несовместимой лицензией.
